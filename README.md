### 🏛️ Backend Architecture & Engineering Philosophy

```
  [ Client Applications (Web / Mobile) ]
                    │  (HTTPS / WSS)
                    ▼
          [ Nginx Reverse Proxy ]
                    │
          [ Laravel 12 API Gateway ] ────── [ Redis Caching & Queues ]
                    │                                   │
        ┌───────────┴───────────┐                       ▼
        ▼                       ▼              [ Background Workers ]
  [ Domain Microservices ] [ Reverb WebSockets ]        │
        │                       │                       ▼
        ▼                       ▼              [ Third-Party APIs ]
  [ Optimized MySQL DB ] [ Real-Time Clients ] (Stripe, Webhooks, FCM)
```

1. **Domain-Driven & Clean Design:** Decoupled business logic using Services, Action classes, and Repositories for long-term maintainability.
2. **Database Performance First:** Eliminating N+1 queries, optimizing relational schemas, and keeping API response times consistently under **80ms**.
3. **Resilient Integrations:** Idempotent payment processing pipelines (Stripe, SSLCommerz, bKash) and fault-tolerant webhook listeners with exponential retry backoff.
4. **Zero-Downtime Reliability:** Managing database migrations safely, managing background queues, and implementing robust error logging.
