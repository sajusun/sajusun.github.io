Frequently Asked Questions

How do we collaborate across different time zones?

I am based in Dhaka, Bangladesh (UTC+6), which conveniently bridges European and Asian working hours, with substantial overlap for US mornings. I excel in asynchronous workflows using Slack, GitHub Pull Requests, and Loom walkthroughs, supplemented by scheduled synchronous syncs.

Do you work on existing legacy codebases or only greenfield projects?

Both. I frequently take on existing Laravel/PHP applications burdened by slow queries, messy controllers, or outdated dependencies, refactoring them into clean modular architectures with zero downtime.

What does your AWS cloud infrastructure service include?

Full lifecycle setup: VPC networking, EC2 compute instances, Aurora/RDS MySQL/Postgres database clusters, S3 asset buckets, Application Load Balancers (ALB) with SSL certificates, and secure GitHub Actions CI/CD pipelines using temporary OpenID Connect (OIDC) tokens.

How soon can we kick off a project?

Depending on current sprint capacity, initial discovery consultations can take place within 24–48 hours of submitting your project specifications via the Quote Form.
